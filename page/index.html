Beta Quest Seed Explorer

Ocarina of Time Beta Quest bingo: a seed's board, how hard each square is, and a way to it.

The BingoSync seed number, from 1 to 999999.

Pick a seed

Type a BingoSync seed number. The page makes the same 25-square board BingoSync does and the same shuffled doors Beta Quest does, then works out which squares need glitches, how much work each one is, and a route to it from where a new file starts.
